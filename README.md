# مكتب الياسمين — موقع تعريفي

موقع عربي باتجاه RTL، مبني بملفات HTML وCSS وJavaScript عادية دون إطار عمل أو خطوات بناء.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادم ملفات محليًا من هذا المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## التخصيص

- غيّر النصوص والعناوين وبيانات الاتصال في `index.html`.
- صور معرض الأعمال موجودة داخل `assets/`، ويمكن استبدالها بصور مشاريع المكتب مع الاحتفاظ بأسماء الملفات أو تعديل مسارات `src` و`data-image`.
- الصور المرفقة أمثلة توضيحية وليست توثيقًا لأعمال المكتب. تحقّق من حقوق استخدامها التجاري واستبدلها بصور مرخّصة/خاصة بالمكتب قبل النشر العام.
- روابط الاتصال تستخدم الرقم `07735448300`، ورابط واتساب بصيغة العراق الدولية `9647735448300`.
- الخط من Google Fonts مع بدائل محلية عند عدم توفر الإنترنت.
